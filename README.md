# 簡報遊戲影片工坊

老師自己做互動簡報遊戲，加上背景音樂和音效，一鍵轉成 MP4 影片上傳 YouTube，帶學員跟著做。

## 兩種遊戲
- **文字圖片配對**：上傳圖片並寫一段文字。圖文符合就做 A 動作（預設雙手比圈），不符合就做 B 動作（預設雙手比叉）。可以批次上傳或拖曳圖片。
- **相反詞／相反動作**：寫一個指令，例如「右手舉高」，再寫它的相反動作。相反動作留白時，會自動把左右、上下、高低、前後對調。

## 可以調整的地方
- 時間：開場、思考倒數、揭曉加做動作、結尾，各自的秒數（以 0.5 秒為單位）。預設揭曉 3 秒，相反動作 2 秒。
- 題目順序：預設隨機出題，也可以依照清單順序
- 原題庫：兩種遊戲都內建題庫，預設影片長度都超過 2 分鐘。按「帶入原題庫」可以隨時換回來。
- 背景音樂（8 種）：歡樂活潑、緊張刺激、動感運動、電玩冒險、俏皮逗趣、溫柔放鬆、拉丁派對、精神進行曲，也可以上傳自己的音樂。內建音樂由程式即時合成，沒有版權問題。
- 音效風格（6 種）：經典提示、電玩闖關、綜藝節目、木琴柔和、卡通搞笑、太空科幻。也能逐項開關（題目出現、每秒滴答、最後 3 秒、揭曉、開場、結尾）。
- 外觀：17 種主題模板（孟菲斯、普普漫畫、霓虹復古、極光、包浩斯、手帳等）、6 種字體（黑體、圓體、明體、楷書、粉圓、手寫）、自訂主色
- Logo 與圖片：可以上傳、裁剪（自由、正方形、圓形），並且去背（去除背景色或 AI 智慧去背），直接在預覽畫面上拖曳位置
- 文字：設計者、單位或頻道名稱（預設：鍾孟修 職能治療師／愛迪樂健康促進團隊，可加浮水印），以及畫面上所有固定文字

## 使用方式
用 Chrome 或 Edge 開啟 `index.html`（需要透過網頁伺服器，例如 `python3 -m http.server`）。
- **全螢幕帶操作**：現場直接投影帶活動（空白鍵暫停，← → 切換段落）
- **匯出影片 MP4**：1080p 或 720p。一分鐘的影片大約 20 秒就能匯出完成。
- **下載教案／上傳教案**：存成 `.教案.json`，裡面包含圖片、Logo 和自訂音樂，可以分享給其他老師

## 檔案
- `bank/`：原題庫插畫 16 張（Gemini 生成）
- `render.js`：畫面渲染（預覽、播放、匯出共用）
- `audio.js`：背景音樂合成、音效包、離線混音
- `export.js`：WebCodecs 逐格編碼，用 mp4-muxer 封裝
- `app.js`：編輯器介面
